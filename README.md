# ipdm-oto-2025--SantiagoFranco_ejercicio-4

## Descripción  
Aplicación Android desarrollada en Kotlin con Jetpack Compose que muestra una tarjeta de presentación profesional según el ejemplo dado.  

**Características principales**:  
- Dos secciones componibles: Información personal (logo, nombre, título) y datos de contacto  
- Componente reutilizable `InfoContacto` para teléfono, email y redes
- Diseño responsive que se adapta a diferentes tamaños de pantalla

**Técnicas aplicadas** 
- Uso de `Column`, `Row` y `Box` para el layout  
- Modificadores: `padding`, `size`, `align` y `offset`  
- Externalización de strings y recursos
